# Vietnamese E-Commerce Spam Review Detection
Dự án phát hiện đánh giá spam trên sàn thương mại điện tử Việt Nam sử dụng kết hợp Text, Metadata và Aspect-Based Sentiment Analysis (ABSA).

## Cấu trúc thư mục
- dataset/: Chứa dữ liệu train/dev/test (tải từ Hugging Face ViSpamReviews v2).
- 
otebooks/: Chứa mã nguồn khảo sát dữ liệu (EDA) và mô hình cơ sở (Baseline).
